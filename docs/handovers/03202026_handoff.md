## Done

### Bug Fixes
- **Groups not showing member counts on GroupsPage** — PostgREST embedded join through RLS returned empty arrays. Switched to separate count query with `.in('group_id', gIds)`.
- **Groups not showing members on GroupDetailPage** — Query selected `first_name, last_name` columns that didn't exist (migration 002 wasn't applied yet). Fixed to query only `students(id, name, grade)`.
- **AddMemberModal search broken** — Used `.or('first_name.ilike..., last_name.ilike...')` on non-existent columns. Fixed to `.ilike('name', ...)`.
- **Dashboard cards not clickable** — Added `navigate()` onClick handlers to all 4 stat cards.
- **Schema mismatches across all pages** — Frontend referenced non-existent tables (`group_objectives`, `session_attendance`, `session_objectives`) and columns (`first_name`, `last_name`, `contact_date`, `resolved_at`). Fixed all pages with fallbacks and created migration 002.
