## 2. Description of Service

Beacon is a command center for elementary school counselors, designed to streamline counseling workflows, time tracking, student support documentation, and SB 179 compliance. The Service includes:

- Caseload management and student support tracking
- Counseling session documentation and scheduling
- SB 179 80/20 time compliance monitoring
- Needs assessment and group planning tools
- Reporting and data visualization

**Beacon operates in two modes:**

- **Local Mode:** All data is stored on your device using browser-based storage (IndexedDB). No data is transmitted to or stored on Clear Path servers. Clear Path has no access to your data in Local Mode.
- **Cloud Mode:** Data is stored on Clear Path's cloud infrastructure (Supabase). Cloud Mode requires a signed Data Processing Agreement (DPA) between the District and Clear Path before any student data may be entered.

You may choose your operating mode during setup. Switching from Local to Cloud Mode requires a DPA and will transfer locally stored data to the cloud.
